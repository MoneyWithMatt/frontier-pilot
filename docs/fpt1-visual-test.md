## Simple test steps

1. Launch **Microsoft Flight Simulator 2024** normally from Steam. Developer Mode is not required. Choose **Free Flight**, a small familiar aircraft such as the Cessna 172, daylight and clear/calm weather.
2. Search the world map for **FPT1** (or **Frontier Test Strip**). Select that airport, not MYNN. It should be near Nassau/Lynden Pindling, Bahamas, around **25.035986 N, 77.469426 W**.
3. Set **runway 10** as the departure/start location and begin the flight. This should place you at the **west end, facing approximately east**. Use external/drone view for a screenshot, then taxi slowly along the strip.
4. Return to flight planning and repeat from **runway 28**. This should place you at the **east end, facing approximately west**. Check that this start is also on the runway and points along it.
5. From above, check the whole runway and its edges. Take an overhead screenshot and a low side-on screenshot where the runway meets the terrain. If convenient, make a short takeoff/circuit/landing after the taxi checks.

If FPT1 is absent, try its full name and check the Nassau area. In My Library, check whether the Frontier package appears and is enabled. Report whether it appears in the library versus on the map; do not change SDK files or remove other scenery to troubleshoot it. A full simulator restart may be needed after changing package activation.
